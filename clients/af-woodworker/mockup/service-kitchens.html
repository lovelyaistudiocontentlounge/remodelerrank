Custom Kitchen Cabinetry

Every kitchen starts as a full 2D and 3D model, not a sketch, so you see the finished cabinetry before a single cut is made. Built by Ahmed and Fernando directly, in Richmond, for homeowners across the Bay Area.

What's included

  • ✓ Full 2D and 3D modeling before production starts
  • ✓ Cabinet boxes, doors, and drawer fronts built in-house
  • ✓ Custom sizing for the actual space, not a stock module
  • ✓ In-house CNC for detail work standard shops sub out
  • ✓ Direct installation by the same team that built it
  • ✓ One point of contact, start to finish: Ahmed or Fernando

Questions before you start

Do you work from my existing kitchen layout, or design a new one?

Either. We model the space as it exists, then work with you on layout before any cabinetry gets designed around it.

Can I see the design before anything is built?

Yes, that's the point of the 2D/3D step. You're seeing the finished cabinetry, not imagining it from a drawing.

Do you handle installation too, or just the cabinets?

Both. The same team that builds it installs it, so nothing gets lost in a handoff to someone else.

What areas do you serve?

Richmond and across the Bay Area. Recent kitchens have been in Oakland, Menlo Park, and San Francisco.
