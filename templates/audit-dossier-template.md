# Audit Dossier Template

Source: contractor-portfolio-lookbook-master-brief.md (website repo, CONTENT/). One
copy per client/prospect, saved to `clients/<slug>/audit/audit-dossier.md`.

Every field carries a **Source** note. If a field is inferred rather than confirmed,
the Source column must say so (`inferred` or `assumed, unverified`) instead of being
left to read as fact. This mirrors the Source-column convention already used in
`clients/coda-construction/website/DISCOVERY.md` - keep using that pattern here.

## 3. Photography Inventory

Do not re-invent a separate grading rubric here. Run
`skills/portfolio-recovery/SKILL.md` Stage 1 (grade/bucket/rank) on the client's
photo folder and link the resulting `clients/<slug>/photos/review/grades.json` +
contact sheet here. That rubric (hero_score, use: main-hero / category-hero /
gallery / supporting / reject) already covers the brief's A-F categories more
precisely - map as:

| Brief category | portfolio-recovery equivalent |
|---|---|
| A - Hero worthy | use: main-hero |
| B - Project worthy | use: category-hero / gallery |
| C - Detail worthy | high-score crops from any master |
| D - Process | tag separately, not covered by hero_score (shop/install/team photos) |
| E - Needs editing | cleanup_needed score > threshold, routed to Stage 3-5 |
| F - Unusable | use: reject |
